# Six-week delivery gates

1. **Nov 8–14**: Starter, API tests, inventory schema, CSV validation, responsive UI.
2. **Nov 15–21**: Licensed public sales dataset with provenance; seasonal naive + LightGBM; rolling-origin backtests.
3. **Nov 22–28**: Correct multi-batch FEFO simulator, expiry constraints, uncertainty scenarios, property tests.
4. **Nov 29–Dec 5**: OR-Tools constrained purchasing/prep optimization; manager approval; shortage/cost trade-offs.
5. **Dec 6–12**: Reproducible held-out evaluations, sensitivity analyses, safety review, optional consented restaurant pilot.
6. **Dec 13–19**: Anonymous judge deployment, README, public repository, license and dataset rights, 2–3 minute YouTube/Vimeo demo, Devpost description, Theme impact paragraph, submit and verify links.

## Arbiter Theme rubric
- Impact on waste problem: 35% — measure waste against credible baseline; label simulations.
- Technical execution: 25% — verified forecasting, simulation and optimizer.
- Feasibility: 20% — practical constraints, cost, operator workflow.
- Presentation: 20% — clear video, reproducible evidence and honest limitations.

## Critical safety and integrity requirements
- Do not recommend serving expired or unsafe food.
- Do not fabricate pilot outcomes, real waste savings or forecast accuracy.
- No automatic orders, donations or food safety decisions.
- Keep source data provenance and licensing records.
- Verify student eligibility and prior-work rules with organizer.
