# Data policy

No external datasets are bundled. The UI scenario is synthetic and the local sales endpoint uses user-entered local demo records only. It must not be described as restaurant pilot data.

Before adding M5, FAO, USDA, or other external data, record source URL, license, acquisition date, fields used, intended-use fit, preprocessing, and limitations under `data/provenance/`. Retail benchmark demand must not be presented as restaurant waste data.
